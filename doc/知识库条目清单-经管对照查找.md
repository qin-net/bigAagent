# 四个分析角色：请分别找资料（总说明）

系统有四个分析角色，资料请 **按角色分开交**。

| 角色 | 看什么 | 请打开这一份去找 |
|------|--------|------------------|
| 基本面 | 财报、估值、现金流、负债 | `知识库资料-基本面Agent.md` |
| 技术面 | 均线、MACD、RSI、量价 | `知识库资料-技术面Agent.md` |
| 情绪 / 事件 | 减持、回购、问询、立案、预告等公告 | `知识库资料-情绪事件Agent.md` |
| 宏观 | 利率、货币政策、和个股是否相关 | `知识库资料-宏观Agent.md` |

**资料就是要找全。** 程序不会把这些书一次读完。你们交来的是原料；我们会拆成一条条短知识，分析某只股票时按「碰到了什么问题」每次只翻几条，不够再翻，不是从头到尾啃图书馆。

每份里面写了完整文件名、作者或机关、文号或 ISBN、能给的官网链接。请下载 **全书 / 全文 PDF**，不要只交标题或摘要。

不用写综述、不用做 PPT。每人交一张表：资料全名、从哪下的、是不是全文。

法规只认财政部、证监会、交易所、央行、统计局官网的现行有效文本。教材走图书馆或正版。论文下期刊全文。
