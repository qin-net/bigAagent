【软件全称】基于多智能体分权协作的 A 股研究辅助系统  
【软件简称】bigAagent  
【版本号】V1.0  
【开发的硬件环境】：Apple M2 Pro 处理器（10 核）16GB 内存  
【运行的硬件环境】：Apple M2 Pro 处理器（10 核）16GB 内存；亦可在同等性能的 64 位 Windows / Linux 个人计算机上运行  
【开发该软件的操作系统】：macOS  
【软件开发环境 / 开发工具】：Visual Studio Code / Cursor；Python 3.9 虚拟环境  
【该软件的运行平台 / 操作系统】：macOS、Windows 10、Windows 11、常见 Linux 发行版（本机浏览器访问本地服务）  
【软件运行支撑环境 / 支持软件】：Python 3.9；现代浏览器（Chrome / Safari / Edge 等）；分析、追踪与画像生成需配置大模型接口密钥  
【编程语言】：Python（辅以 JavaScript、HTML、CSS）  
【源程序量】：18953  
【开发目的】：实现 A 股研究辅助的多智能体分权交卷、模拟记账与持续追踪，把研究、决策、纪律留在同一条链路，学费停在模拟盘。  
【面向领域 / 行业】：金融科技、证券研究辅助、投研教学与个人学习  
【软件的主要功能】：基于多智能体分权协作的 A 股研究辅助系统是面向延迟行情的专业级研究工作台，集成延迟行情采集、四维首次分析、口径反馈与按维重跑、模拟投资记账、手动追踪复核、用户画像与专家记忆六大核心模块。支持全市场延迟报价入库、按代码或名称检索并打开标的详情；由基本面、技术面、情绪、宏观四位专家并行交卷，系统综合形成可追踪基线；用户可补充可执行口径，过闸门后记住并按维度约束下一次分析，原话不落盘、不当行情证据；分析完成后可用虚拟资金按延迟价成交，持仓随行情重估，买入理由写入选股记忆；有基线后由用户手动触发追踪，对照原判断给出维持、复核或证伪，不按小时自动巡检；提供投资者画像生成、口径停用，以及按专家隔离的私有记忆工作台。包含商品级研究流程中的标的详情、K 线与公告、自选管理、模拟账户总览等功能。延迟行情仅供研究辅助，不构成投资建议，不连接实盘交易。  
【技术特点】：使用 Python 开发，基于大模型原生函数调用的多智能体运行时；专家状态与上下文分离，记忆按角色隔离，综合决策由系统环节完成而非第六个总控智能体。  
【软件分类】：应用软件  
【技术特点类型】：人工智能软件
