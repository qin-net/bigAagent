# 看板模拟投资与选股记忆

> 状态：已实现  
> 位置：本仓库 `doc/`  
> 关联：`看板接入研究功能-B2.md`、`个人投资决策手册.md`

研究 Agent 仍不对池子选股。看板增加两块本地能力：

1. **选股记忆**：全局纪律或「这只票为什么进池子」的短句，落在 `board.db` 的 `pick_memory`。不存长文原话，上限 200 字，可停用。
2. **虚拟资金模拟**：默认 100 万虚拟本金。按当前批次延迟价成交（100 股整数倍）。持仓市值 = 数量 × 现价，总资产 = 现金 + 市值，随下一批行情涨跌变动。

不是实盘、不承诺收益。成交与计价都用看板延迟行情。
