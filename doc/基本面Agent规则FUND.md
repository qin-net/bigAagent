# 基本面 Agent 量化分析规则（FUND 规则集）

## 总体设计说明（写给软件同学）

1. **规则出处原则**：知识库内直接可引用的"价值投资"原著为格雷厄姆《聪明的投资者》、Piotroski(2000)、Sloan(1996)、Penman 两篇、Damodaran 两本、Palepu《经营分析与估值》及多篇 A 股盈余质量实证论文。巴菲特、芒格、费雪本人的原始著作**不在**本知识库内，凡涉及他们的思想，均注明其量化支撑来自上述库内文献，不出现无出处的数字。
2. **打分汇总**：每条规则产出 `-1 / 0 / +1 / +2` 四档得分，各规则等权（或按维度加权）求和得到"基本面总分"；建议把每一条都做成独立函数 `score_FUND_XX(data) -> int`，便于单独调试与 A/B。
3. **数据获取**：统一使用 AKShare，接口名以当前版本为准（字段名可能随版本微调，见每条【所需数据】）。
4. **行业适配**：杠杆类规则（FUND-07）和估值类规则（FUND-01/02）对金融、地产等特殊行业需单独配置阈值，已在规则内注明。

## 裁决优先级与数据口径（总则，先于具体规则）

> 本总则解决三类规则裁决缺口，必须与 FUND-01~FUND-11 一起落地到代码（`apply_fundamental_rules`）与 Agent 提示词。

### 0.1 裁决优先级：现金流 / 盈利质量 > 估值便宜

- 估值便宜（PE 分位低、PB 低）是买入的**必要非充分条件**，不是充分条件。
- 当「便宜」与「现金流为负 / 盈利质量差」同时出现、且现金流为负无法归因于季节性时，判**价值陷阱风险**（Penman），结论**最多 hold，不得 buy**。
- 只有现金流（尤其自由现金流）能验证的便宜才成立（Damodaran 估值须对照现金流；Graham 安全边际要求「利润以现金为证」）。

### 0.2 ROE 必须看长期，单期报告期 ROE 不得直接判「不合格」

- 巴菲特「长期维持高于 15% 的 ROE」是**多年年度**口径，不是单季/单报告期。
- 落地顺序：① 连续≥3 年年度 ROE（均值≥15% 且最低年≥12% 且负债率<60%）→ ② 数据层已确认长期稳定（`roe_stable`）→ ③ 仅单期报告期 ROE：**先年化**（Q1×4、中报×2、Q3×4/3、年报×1）再与 15% 比较，且只能作趋势参考。
- 单期 ROE 即使年化后 <15%，结论也是「需年报/多年 ROE 确认长期性」，**不能**写成「ROE 不合格」。

### 0.3 现金流与利润背离：三步归因，不能笼统判「现金流差」

当利润同比为正、经营现金流为负（`cashflow_lag` 触发）时，必须归因后裁决：

1. **季节性 / 回款节奏**：对照历史同期现金流；若现金流同比改善（`cashflow_yoy>0`）或行业为预收款模式（白酒 Q1 收预收款、年中为负），属常态而非恶化 → `cashflow_seasonal`。
2. **盈利含金量**：经营现金流/净利润（同口径 TTM 或全年）<0.5 或连续两期为负 → 应计过高、质量恶化（Sloan 1996）→ `cashflow_quality_issue`。
3. **会计处理差异**：利润增长主要来自非经常性损益（政府补助、减值转回等），剔非后经常性利润未增 → 含金量低（魏涛 2007）→ `non_recurring_warning`。

数据不足以区分时（无现金流同比、无 TTM 现金流），按「需年报/累计口径确认」处理，并在风险里列「现金流转正」作为可检验证伪。

### 0.4 数据口径（防错配，与 AKShare 接口对应）

| 字段 | 接口来源 | 实际口径 | 与年度门槛比较时的处理 |
|---|---|---|---|
| roe | `stock_financial_abstract_ths(indicator="按报告期")`「净资产收益率」 | 报告期累计（如中报=半年累计），非 TTM、非年度 | 年化后比较，且以多年年度为准 |
| operating_cf | `stock_cash_flow_sheet_by_report_em` `NETCASH_OPERATE` | 报告期累计经营现金流（元），非全年 | 取全年/TTM 或对照历史同期 |
| profit_yoy | `stock_financial_abstract_ths`「净利润同比增长率」 | 报告期同比（如中报 vs 上年中报） | 与现金流**同比**对照，勿与现金流**绝对值**对照 |

### FUND-01 市盈率安全边际（估值）

- **来源文献**：《聪明的投资者》第14章「防御型投资者的股票选择」（市盈率不超过过去3年平均盈利的15倍，且市盈率×市净率≤22.5）；《公司理财》第9章（市盈率估值法）。
- **大师思想**：格雷厄姆的"安全边际"——买入价格必须显著低于合理价值。防御型投资者买入的市盈率不应超过 15 倍，且用 PE×PB≤22.5 同时约束"不要太贵 + 有资产支撑"。
- **量化标准**：
  - PE_TTM ≤ 15 → 优秀（+2）
  - 15 < PE_TTM ≤ 25 → 合格（+1）
  - 25 < PE_TTM ≤ 40 → 谨慎（0）
  - PE_TTM > 40 或 PE_TTM < 0（亏损）→ 不合格（-1）
  - 附加校验：PE_TTM × PB ≤ 22.5 时额外 +1
- **所需数据**：`ak.stock_a_indicator_lg(symbol)` 的 `pe_ttm`（滚动市盈率）、`pe`、`pb` 字段。
- **打分逻辑**：先按 PE_TTM 分档给分，再叠加 PE×PB 校验加分；PE<0（亏损）直接判 -1。
- **示例判断**：PE_TTM=12、PB=1.6 → 12≤15 优秀 +2；12×1.6=19.2≤22.5 → +1，合计 +3（估值安全边际充足）。PE_TTM=38 → 谨慎 0 分。

### FUND-02 市净率/资产安全边际（估值）

- **来源文献**：《聪明的投资者》第14章（股价/资产比≤1.5倍）、第18章「安全边际」；Piotroski(2000) 市净率筛选信号。
- **大师思想**：格雷厄姆认为股价不应高于账面值（净资产）的 1.5 倍，净资产为股价提供"地板"，低于资产的买入才具备安全边际。
- **量化标准**：
  - PB ≤ 1.5 → 优秀（+2）
  - 1.5 < PB ≤ 3 → 合格（+1）
  - 3 < PB ≤ 5 → 谨慎（0）
  - PB > 5 或净资产为负 → 不合格（-1）
- **所需数据**：`ak.stock_a_indicator_lg(symbol)` 的 `pb`；净资产为负可结合 `ak.stock_financial_abstract_ths` 的「每股净资产」或 `ak.stock_balance_sheet_by_report_em` 的股东权益合计判断。
- **打分逻辑**：按 PB 分档给分；净资产为负（PB 无意义）直接 -1。
- **示例判断**：PB=1.2 → 优秀 +2。PB=8（高 ROE 消费龙头）→ 不合格 -1（格雷厄姆视角资产支撑不足，需靠盈利与成长规则补分）。

### FUND-03 净资产收益率 ROE（盈利能力）

- **来源文献**：Piotroski(2000) F-Score「盈利能力」组信号（ROA>0、经营现金流>0、ΔROA>0）；Penman《财务报表分析与证券估值》盈利能力分析章节（ROE 分解）；Damodaran《Investment Valuation》关于 ROE 与可持续增长的讨论。
- **大师思想**：巴菲特认为优秀公司的标志是长期维持高于 15% 的净资产收益率且可持续（该思想承接格雷厄姆对"充足且稳定盈利"的要求，并由 Piotroski 的 ROA 信号给出实证量化）。
- **量化标准**（取最近 5 个年度 ROE，要求数据齐全）：
  - 5 年 ROE 均 ≥ 15% → 优秀（+2）
  - 5 年均值 ≥ 15%，但个别年份 < 15% → 合格（+1）
  - 5 年均值在 10%～15% → 一般（0）
  - 5 年均值 < 10% 或出现连续亏损 → 不合格（-1）
- **所需数据**：`ak.stock_financial_abstract_ths(symbol, indicator="按报告期")` 的「净资产收益率」字段；或 `ak.stock_financial_analysis_indicator(symbol, start_year)` 的「净资产收益率」逐年取值。
- **打分逻辑**：按 5 年 ROE 的均值与稳定性分档；均值 < 10% 或连续亏损记 -1。
- **示例判断**：5 年 ROE = 16%、18%、17%、15%、19%（均值 17%，全 ≥15%）→ 优秀 +2。另一家 5 年 ROE = 8%、9%、7%、10%、9%（均值 8.6%）→ 不合格 -1。

### FUND-04 盈利质量：经营现金流/净利润（应计项目）

- **来源文献**：Sloan(1996)《Do Stock Prices Fully Reflect Information in Accruals and Cash Flows about Future Earnings?》；Dechow & Dichev(2002)《The Quality of Accruals and Earnings》；彭韶兵等(2008)《信息可靠性、企业成长性与会计盈余持续性》。
- **大师思想**：Sloan 的核心发现——盈余中"应计项目"（账面利润与现金流的差额）占比越高，盈余持续性越差、未来回报越低，因为应计包含大量主观估计。现金流成分比应计成分更可靠。格雷厄姆同样强调"利润须以真金白银的现金为证"。
- **量化标准**（CFO=经营现金流净额，NP=净利润，取最近年度或近 3 年合计）：
  - CFO / NP ≥ 1 → 优秀（+2）
  - 0.8 ≤ CFO/NP < 1 → 合格（+1）
  - 0.5 ≤ CFO/NP < 0.8 → 谨慎（0）
  - CFO/NP < 0.5 或 CFO < 0 → 不合格（-1）
  - 注：NP ≤ 0 时本规则不适用，转由 FUND-03/05 处理。
- **所需数据**：`ak.stock_cash_flow_sheet_by_report_em(symbol)` 的「经营活动产生的现金流量净额」；`ak.stock_profit_sheet_by_report_em(symbol)` 的「净利润」。
- **打分逻辑**：计算 CFO/NP 比率分档；CFO < 0 直接 -1。
- **示例判断**：净利润 10 亿、经营现金流净额 11 亿 → 1.1 ≥ 1 → 优秀 +2。净利润 8 亿、现金流 2 亿 → 0.25 < 0.5 → 不合格 -1（利润高度依赖应计，持续性存疑）。

### FUND-05 营收与净利润成长（成长能力）

- **来源文献**：《聪明的投资者》第14章（盈利增长：过去10年每股收益至少增长1/3）；Palepu《经营分析与估值》第2章（战略与增长分析）、Damodaran 关于增长驱动因素的讨论（承接费雪"成长股"思想）。
- **大师思想**：格雷厄姆要求盈利有稳定的增长记录；费雪关注"营收与利润的长期持续成长，且由主营业务而非一次性项目驱动"。
- **量化标准**（取最近 3 年复合增长率 CAGR，或年度同比）：
  - 营收 CAGR ≥ 10% 且 扣非净利 CAGR ≥ 10% → 优秀（+2）
  - 营收与扣非净利 CAGR 均 ≥ 5% → 合格（+1）
  - 营收或扣非净利 CAGR 在 0～5% → 一般（0）
  - 营收或扣非净利 CAGR < 0（负增长）→ 不合格（-1）
- **所需数据**：`ak.stock_financial_abstract_ths` 的「营业总收入同比增长率」「净利润同比增长率」；或 `ak.stock_financial_abstract` 的「营业总收入」「扣非净利润」逐年计算 CAGR。
- **打分逻辑**：营收与扣非净利增速双达标才给高分；任一负增长记 -1。
- **示例判断**：营收 20→24→30 亿（CAGR≈22%），扣非净利 3→3.6→4.5 亿（CAGR≈22%）→ 优秀 +2。另一家营收 CAGR=-3%、扣非净利 CAGR=-8% → 不合格 -1。

### FUND-06 成长质量 / 价值陷阱识别（成长能力）

- **来源文献**：Penman & Reggiani(2014)《The Value Trap: Value Buys Risky Growth》；Penman《财务报表分析与证券估值》。
- **大师思想**：Penman 指出，高账面/市值比（"价值"）公司的"便宜"往往对应"有风险的增长"——账面确认的成长可能伴随较高经营风险或会计激进/保守。安全投资需要"盈利质量高 + 增长可持续"，而非单纯低估值或高增长数字，以此规避"价值陷阱"。
- **量化标准**（交叉判断"增长"与"盈利质量"）：
  - 净利 CAGR ≥ 5% 且 CFO/NP ≥ 0.8 → 健康增长（+2）
  - 增长为正但 CFO/NP < 0.8 → 存疑增长（0）
  - 净利 CAGR < 5% 且 PB < 1.5 且 CFO/NP < 0.8 → 价值陷阱预警（-1）
  - 无增长且亏损 → 不合格（-1）
- **所需数据**：`stock_financial_abstract_ths`（增长）+ `stock_cash_flow_sheet_by_report_em`/`stock_profit_sheet_by_report_em`（CFO/NP）+ `stock_a_indicator_lg`（PB）。
- **打分逻辑**：交叉判定"增长 × 盈利质量"，识别"便宜但有风险"的组合；健康增长 +2，价值陷阱 -1。
- **示例判断**：PB=1.2（看似便宜）、净利 CAGR=+4%、CFO/NP=0.3 → 价值陷阱预警 -1。PB=2.5、净利 CAGR=15%、CFO/NP=1.2 → 健康增长 +2。

### FUND-07 财务稳健性：流动性与负债（财务风险）

- **来源文献**：《聪明的投资者》第14章第2条"足够强劲的财务状况"（流动比率≥2、长期债务不超过营运资本）；《公司理财》第3章（流动性与偿债能力指标）。
- **大师思想**：格雷厄姆要求防御型投资者买入的公司财务强健——流动资产足以覆盖流动负债、长期债务不超过营运资本，以抵御下行风险。
- **量化标准**（流动比率 = 流动资产/流动负债）：
  - 流动比率 ≥ 2 且 资产负债率 ≤ 50% → 优秀（+2）
  - 流动比率 ≥ 1.5 且 资产负债率 ≤ 60% → 合格（+1）
  - 流动比率 ≥ 1 且 资产负债率 ≤ 70% → 一般（0）
  - 流动比率 < 1 或 资产负债率 > 70% → 不合格（-1）
  - 注：金融、地产等高杠杆行业需单独下调阈值。
- **所需数据**：`ak.stock_financial_analysis_indicator` 的「流动比率」「资产负债率」；或 `ak.stock_financial_abstract_ths` 的「资产负债率」+ `stock_balance_sheet_by_report_em` 的流动资产/流动负债计算。
- **打分逻辑**：流动比率与资产负债率双约束，取较严一档；任一触发红线记 -1。
- **示例判断**：流动比率=2.3、资产负债率=45% → 优秀 +2。流动比率=0.8、资产负债率=75% → 不合格 -1。

### FUND-08 商誉减值风险（财务风险 / 管理层质量）

- **来源文献**：李安泰等(2022)《机构投资者能抑制上市公司商誉减值风险吗》；《企业会计准则第8号——资产减值》（商誉至少每年年度终了进行减值测试）；《企业会计准则第20号——企业合并》（商誉确认）。
- **大师思想**：商誉源于溢价并购，若并购溢价未能转化为持续盈利能力即触发减值、吞噬利润。芒格警惕管理层"为并购而并购"的高溢价行为，视巨额商誉为风险信号；李安泰等发现机构投资者持股能抑制商誉减值风险。
- **量化标准**（商誉占净资产比例，取最近报告期）：
  - 商誉 / 净资产 ≤ 10% → 低风险（+2）
  - 10% < 商誉/净资产 ≤ 20% → 关注（+1）
  - 20% < 商誉/净资产 ≤ 30% → 警示（0）
  - 商誉/净资产 > 30% → 高风险（-1）
  - 附加：最近年度商誉减值损失 / 净利润 > 30% → 额外 -1
- **所需数据**：`ak.stock_balance_sheet_by_report_em` 的「商誉」「股东权益合计」字段；减值损失取 `ak.stock_profit_sheet_by_report_em` 的「资产减值损失」。
- **打分逻辑**：按商誉/净资产比例分档，再叠加减值损失占比惩罚项。
- **示例判断**：商誉 5 亿、净资产 50 亿 → 10% → 低风险 +2。商誉 40 亿、净资产 60 亿 → 67% > 30% → 高风险 -1。

### FUND-09 非经常性损益占比（会计质量 / 管理层质量）

- **来源文献**：魏涛等(2007)《非经常性损益盈余管理的动机、手段和作用研究》；谭燕(2008)《资产减值准备与非经常性损益披露管制》；证监会《解释性公告第1号——非经常性损益（2023年修订）》。
- **大师思想**：魏涛等发现 A 股上市公司利润严重依赖非经常性损益（处置资产、政府补助等）实现扭亏、避亏、平滑利润；扣非净利润才是真实经营盈利能力的体现。格雷厄姆/巴菲特强调"看经营利润，剔除一次性、偶发性损益"。
- **量化标准**（扣非净利润 / 净利润，取最近年度）：
  - 扣非净利 / 净利润 ≥ 0.9 → 优秀（+2）
  - 0.7 ≤ 扣非/净利 < 0.9 → 合格（+1）
  - 0.5 ≤ 扣非/净利 < 0.7 → 谨慎（0）
  - 扣非/净利 < 0.5，或"净利润为正但扣非为负" → 不合格（-1）
  - 注：净利润 ≤ 0 时本规则不适用。
- **所需数据**：`ak.stock_financial_abstract`（东财财务摘要）的「净利润」「扣非净利润」字段。
- **打分逻辑**：计算扣非/净利比率分档；"净利为正但扣非为负"直接 -1。
- **示例判断**：净利润 5 亿、扣非 4.8 亿 → 0.96 ≥ 0.9 → 优秀 +2。净利润 2 亿、扣非 0.3 亿 → 0.15 < 0.5 → 不合格 -1。

### FUND-10 内部控制质量（管理层质量 / 会计质量）

- **来源文献**：方红星、张志平(2013)《内部控制对盈余持续性的影响及其市场反应》；证监会《上市公司信息披露管理办法》（内控/风险披露要求）。
- **大师思想**：方红星等发现内控质量越高、盈余（应计与现金流成分）持续性越强，内控缺陷公司盈余质量更低。芒格强调"管理层诚信与公司治理"——内控是治理与会计质量的制度保障。
- **量化标准**（取最近年度内控审计意见与缺陷）：
  - 内控审计意见为标准无保留（无重大缺陷）→ 优秀（+2）
  - 带强调事项段 / 存在一般缺陷 → 谨慎（0）
  - 存在内控重大缺陷 / 内控否定意见 / 财报重述 → 不合格（-1）
- **所需数据**：内控审计意见需解析年报/内控评价报告文本：`ak.stock_zh_a_disclosure_report_cninfo(symbol, market="沪深京")` 获取公告列表与链接，再对《内部控制评价报告》《内部控制审计报告》做文本解析判定意见类型；财报重述可由公告关键词检索辅助判断。
- **打分逻辑**：按内控审计意见类型分档；重大缺陷或财报重述记 -1。
- **示例判断**：内控审计意见为标准无保留、无重大缺陷 → 优秀 +2。当年被出具内控否定意见（存在重大缺陷）→ 不合格 -1。

### FUND-11 毛利率与竞争优势（护城河）

- **来源文献**：Palepu & Healy《经营分析与估值》第2章（战略分析：行业结构、竞争优势与超额利润来源）；Damodaran《Little Book of Valuation》/《Investment Valuation》关于"护城河与可持续超额回报（ROIC > 资本成本）"的讨论（承接巴菲特/芒格"护城河"思想与费雪的产品/研发壁垒思想）。
- **大师思想**：巴菲特/芒格认为伟大企业拥有可持续的"护城河"（品牌、规模、网络效应、转换成本、特许权），表现为长期高且稳定的毛利率与超额资本回报。Palepu 从战略角度给出：竞争优势 → 超额利润 → 高且稳定的毛利。
- **量化标准**（毛利率 =（营收−营业成本）/营收，取最近 5 年均值与稳定性）：
  - 5 年毛利率均值 ≥ 30% 且波动小（标准差/均值 < 20%）→ 强护城河（+2）
  - 5 年毛利率均值 ≥ 20% → 合格（+1）
  - 5 年毛利率均值在 10%～20% → 一般（0）
  - 5 年毛利率均值 < 10% 或逐年持续下滑 → 弱（-1）
- **所需数据**：`ak.stock_financial_abstract_ths` 的「销售毛利率」字段；或用 `ak.stock_profit_sheet_by_report_em` 的「营业总收入」「营业成本」逐年计算。
- **打分逻辑**：按 5 年毛利率均值与稳定性分档；持续下滑记 -1。
- **示例判断**：5 年毛利率 = 45%、44%、46%、45%、47%（均值 45.4%、波动极小）→ 强护城河 +2。另一家 = 12%、11%、9%、8%、7%（均值 9.4% 且持续下滑）→ 弱 -1。

### FUND-12 自由现金流 FCF 质量与估值（现金流）

- **来源文献**：Damodaran《Little Book of Valuation》《Investment Valuation》（估值须基于现金流而非会计利润，自由现金流 FCFE/FCFF 是估值核心输入）；《企业会计准则第31号——现金流量表》+《应用指南汇编2024》现金流量表章（经营/投资/筹资三分类，购建固定资产等资本开支属投资活动流出）。
- **大师思想**：Damodaran——会计利润可被应计操纵，自由现金流才是股东真正可支配的现金；估值必须对照经营现金流与自由现金流，不能只看 PE。格雷厄姆"利润须以真金白银为证"。本规则直接承接用户偏好「估值对照经营现金流与自由现金流」。
- **量化标准**（FCF = 经营现金流净额 CFO − 资本开支 CapEx）：
  - FCF > 0 且 FCF/NP ≥ 0.8 → 优秀（+2）
  - FCF > 0 且 0.5 ≤ FCF/NP < 0.8 → 合格（+1）
  - FCF > 0 且 FCF/NP < 0.5，或 FCF ≤ 0 → 谨慎（0）
  - FCF < 0 且连续两期（自由现金流持续流出）→ 不合格（-1）
  - 附加：FCF 收益率（FCF / 总市值）≥ 5% → 额外 +1
  - 注：NP ≤ 0 时本规则与 FUND-04 联动，优先看 FCF 能否为正。
- **所需数据**：`stock_cash_flow_sheet_by_report_em` 的「经营活动产生的现金流量净额」「购建固定资产、无形资产和其他长期资产支付的现金」；`stock_a_indicator_lg` 的 `total_mv`（总市值）。
- **打分逻辑**：先判 FCF 正负与 FCF/NP 分档，再看 FCF 收益率加成；FCF 持续为负记 -1。
- **示例判断**：CFO=50 亿、CapEx=20 亿 → FCF=30 亿 >0；NP=40 亿 → FCF/NP=0.75 → 合格 +1；FCF 收益率=30/600=5% → +1，合计 +2。另一家 CFO=10 亿、CapEx=35 亿 → FCF=-25 亿 → 谨慎 0（连续两期为负则 -1）。

### FUND-13 Piotroski F-Score 综合九项（盈利质量 / 价值股筛选）

- **来源文献**：Piotroski(2000)《Value Investing: The Use of Historical Financial Statement Information to Separate Winners from Losers》。
- **大师思想**：Piotroski 用 9 个二分信号，把"账面/市值比高（看起来便宜）"的价值股进一步分成赢家与输家——基本面信号强（F-Score 高）的便宜才是真便宜，信号弱的便宜是价值陷阱。这是对 FUND-06 价值陷阱识别的量化落地。
- **量化标准**（9 项各 +1，满分 9）：
  1. 净利润 > 0（ROA>0）
  2. 经营现金流 CFO > 0
  3. ΔROA > 0（ROA 同比上升）
  4. CFO > 净利润（应计为负，Sloan 呼应）
  5. 长期负债率同比下降
  6. 流动比率同比上升
  7. 无股权增发（股本未扩张）
  8. 毛利率同比上升
  9. 资产周转率同比上升
  - F-Score ≥ 7 → 优秀（+2）
  - 5 ≤ F-Score ≤ 6 → 合格（+1）
  - 3 ≤ F-Score ≤ 4 → 谨慎（0）
  - F-Score ≤ 2 → 不合格（-1）
- **所需数据**：需两年对比数据——`stock_financial_abstract_ths` / `stock_financial_analysis_indicator`（ROA、净利润、毛利率、资产周转率、流动比率、长期负债率）+ `stock_cash_flow_sheet_by_report_em`（CFO）+ 股本变动（增发）。
- **打分逻辑**：9 项二分信号累计成 F-Score，再分档给分。
- **示例判断**：F-Score=8（9 项中 8 项为真）→ 优秀 +2。F-Score=2 → 不合格 -1（便宜但基本面恶化，价值陷阱）。

### FUND-14 资本回报与 ROE 来源（杜邦分解 / ROIC vs 资本成本）

- **来源文献**：Penman《财务报表分析与证券估值》（ROE 分解为净利率×资产周转×权益乘数，残值收益模型把 PB、ROE、资本成本联结）；Damodaran《Investment Valuation》（ROIC > 资本成本才创造价值）；CPA《财务成本管理》（资本成本 WACC、经济增加值）。
- **大师思想**：巴菲特/芒格"护城河 = 长期 ROIC 持续高于资本成本"；杜邦分解判断 ROE 质量是来自利润率（产品/品牌力）还是杠杆（财务风险）——靠高杠杆撑起的高 ROE 脆弱，靠净利率和周转撑起的才可持续。
- **量化标准**（ROIC ≈ 税后经营净利 / 投入资本；WACC 按公司加权资本成本）：
  - ROIC − WACC > 0（持续）且 ROE 由净利率/周转驱动、权益乘数不高 → 优秀（+2）
  - ROIC − WACC > 0 但杠杆偏高 → 合格（+1）
  - ROIC − WACC ≈ 0 → 谨慎（0）
  - ROIC < WACC（持续）或 高 ROE 完全靠高杠杆（权益乘数 > 5）→ 不合格（-1）
- **所需数据**：`stock_financial_analysis_indicator` 的「销售净利率」「总资产周转率」「权益乘数」；ROIC/WACC 需用利润表、资产负债表数据计算。
- **打分逻辑**：先看 ROIC−WACC 正负，再看杜邦三因子来源；杠杆过高记 -1。
- **示例判断**：ROE=18%，杜邦=净利率 20%×周转 0.6×乘数 1.5 → 靠净利率、杠杆低 → 优秀 +2。ROE=18%，杜邦=净利率 3%×周转 1.0×乘数 6.0（高杠杆）→ 脆弱 -1。

### FUND-15 收入质量：营收增速 vs 应收账款增速（收入确认）

- **来源文献**：《企业会计准则第14号——收入》（五步法，控制权转移时确认收入，遏制提前确认）；Sloan(1996)（应收账款属应计，应收虚增拉高利润但无现金）；彭韶兵(2008)（信息可靠性与盈余持续性）。
- **大师思想**：收入是利润的起点，收入确认激进（提前确认、放宽信用、应收虚增）是盈余操纵高发区。应收账款增速持续高于营收增速，说明收入"含金量"下降——卖出去却收不回现金，利润不可靠。
- **量化标准**（对比「应收账款同比」与「营收同比」，取最近年度）：
  - 应收增速 ≤ 营收增速 → 优秀（+2）
  - 应收增速 − 营收增速 ≤ 10pct → 合格（+1）
  - 10pct < 应收增速 − 营收增速 ≤ 30pct → 谨慎（0）
  - 应收增速 − 营收增速 > 30pct，或 营收高增长但经营现金流为负 → 不合格（-1）
- **所需数据**：`stock_financial_abstract_ths`「营业总收入同比增长率」；`stock_balance_sheet_by_report_em`「应收账款」两年对比计算增速。
- **打分逻辑**：算应收增速与营收增速的背离度分档；背离过大记 -1。
- **示例判断**：营收 +20%、应收 +8% → 应收慢于营收 → 优秀 +2。营收 +15%、应收 +45% → 背离 30pct → 不合格 -1（收入含金量存疑）。

### FUND-16 分红与股东回报可持续性（股东回报）

- **来源文献**：Graham《聪明的投资者》（持续分红是盈利真实、现金充沛的佐证，防御型投资者关注长期股息记录）；Ross《公司理财》（股利政策与股利信号，分红率过高会透支经营现金）。
- **大师思想**：长期稳定分红是"利润真实 + 现金流充沛"的信号，也是股东实际回报；但借债分红（分红率>100%）或长期盈利却不分红，都需警惕。
- **量化标准**（分红率 = 每股股利/每股收益；股息率 = 每股股利/股价）：
  - 连续多年稳定分红，且 30% ≤ 分红率 ≤ 70%，且 2% ≤ 股息率 ≤ 6% → 优秀（+2）
  - 有分红但分红率/股息率不在上述区间，或历史分红有波动 → 合格（+1）
  - 长期盈利却不分红 → 谨慎（0）
  - 分红率 > 100%（借债/侵蚀资本分红）或 净利润为负仍高分红 → 不合格（-1）
- **所需数据**：`stock_history_dividend_detail`（分红历史）；`stock_a_indicator_lg` 的 `dv_ratio`（股息率）；每股收益与每股股利计算分红率。
- **打分逻辑**：按分红稳定性、分红率、股息率三区间综合分档；透支分红记 -1。
- **示例判断**：连续 10 年分红、股息率 3%、分红率 50% → 优秀 +2。净利润为负仍大额分红 → 不合格 -1。

### FUND-17 会计信息可靠性与财报重述风险（会计质量 / 管理层质量）

- **来源文献**：彭韶兵(2008)（信息可靠性越高，盈余持续性越强）；证监会《上市公司信息披露管理办法》（真实、准确、完整披露义务）；《编报规则第15号——财务报告的一般规定（2023年修订）》。
- **大师思想**：会计信息可靠是基本面分析的前提；财报重述/会计差错更正意味着历史数据不可信，是重大风险信号。巴菲特"若财报读不懂或不可信，直接放弃"。本规则与 FUND-10 内控联动，构成"数据可信"的一票否决项。
- **量化标准**（基于公告与审计意见，取最近年度）：
  - 无财报重述、无审计保留意见、无监管问询 → 优秀（+2）
  - 有一般性问询/关注函，但无重述、无保留意见 → 谨慎（0）
  - 存在财报重述/会计差错更正/审计保留或否定意见/立案调查 → 不合格（-1，一票否决）
- **所需数据**：公告与问询检索 `stock_zh_a_disclosure_report_cninfo`（年报、更正公告、问询函）+ 审计意见文本解析。
- **打分逻辑**：按风险等级分档；重述/保留意见/立案任一触发即 -1，并应在整体评分中一票否决方向判断。
- **示例判断**：当年发布"前期会计差错更正"公告 → 不合格 -1（历史数据不可信，其余规则结果需打折或弃权）。
