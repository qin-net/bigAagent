## 1. 修改的既有规则（逻辑变了，规则 id 不变）

### 1.1 `roe_quality`（原：单期 `roe>=15 and debt_ratio<60`）

**问题**：原来拿单季/报告期 ROE（如五粮液中报 ROE=6.5）直接和年度 15% 比，把「单季低」误判成「ROE 不合格」。

**新逻辑**（三层，优先取高层，见 `_annualize_roe`）：

1. 有 `roe_series`（连续≥3 年年度 ROE）→ 要求 `均值>=15 且 最低年>=12 且 debt_ratio<60`
2. `roe_stable == True`（数据层已确认长期稳定）→ 要求 `最新 roe>=12 且 debt_ratio<60`
3. 仅单期 `roe` → **先年化**（Q1×4、中报×2、Q3×4/3、年报×1）再比 15；不足时 detail 明确写「single-period is NOT enough to judge long-term ROE quality」，**不再判不合格**

**软件注意**：`roe_quality` 这个 flag 名保持不变，但判定条件变了。原来 fixture（roe=16.8、roe_stable=true）仍会命中（走第 2 层），不影响现有断言。

### 1.2 `cashflow_lag`（原：`profit_yoy>0 and operating_cf<=0`）

**基础触发条件不变**（保持向后兼容），但在其后**新增归因分类**（见 `_classify_cashflow_divergence`）：

| 条件 | 新增 flag |
|---|---|
| `cashflow_yoy > 0`（现金流同比改善） | `cashflow_seasonal`（季节性/回款节奏，非恶化） |
| `ocf_to_np < 0.5`（现金流/净利润过低） | `cashflow_quality_issue`（Sloan 应计质量恶化） |
| 都无数据 | 不加（保持 `undetermined`，仅 `cashflow_lag` 本身） |

**软件注意**：`cashflow_lag` 仍会触发（`evidence.py::require_cashflow_lag_citation` 依赖它），不受影响。

### 1.3 新增组合裁决 `value_trap_risk`（解决「便宜 vs 现金流差」权重）

触发条件：`valuation_cheap` 命中 **且** `cashflow_lag` 命中 **且** 非 `cashflow_seasonal`。

语义：**现金流/盈利质量 > 估值便宜**。便宜 + 现金流为负（非季节性）= 价值陷阱风险，Agent 最多 hold、不得 buy。

## 6. 数据层待办（让新规则真正生效，按优先级）

规则代码已就位、字段已定义，**只差 `market.py` 填充字段**。按优先级：

### P0（对应本次三个核心问题，强烈建议先做）

1. **`roe_report_period`**：`financials()` 里从 `stock_financial_abstract_ths` 的「报告期」字段解析（`2026-06-30` → `h1`、`2026-03-31` → `q1`、`2026-09-30` → `q3`、`2026-12-31` → `fy`）。这样单期 ROE 才能正确年化。
2. **`cashflow_yoy`**：`cashflow()` 里取**连续两期**经营现金流，算同比。这样现金流背离才能区分「季节性 vs 质量恶化」。
3. **`ocf_to_np`**：`cashflow()` 里用**同报告期**的 `operating_cf / net_profit`。
4. **`roe_series`**：`financials()` 里用 `stock_financial_analysis_indicator(symbol, start_year=...)` 逐年取最近 3~5 年年度 ROE（注意取**年报**口径，不是报告期累计）。

### P1（FCF + 收入质量，回应「对照自由现金流」偏好）

5. **`capex` / `fcf`**：`stock_cash_flow_sheet_by_report_em` 的「购建固定资产、无形资产和其他长期资产支付的现金」→ `capex`；`fcf = operating_cf - capex`。
6. **`receivable_yoy`**：`stock_balance_sheet_by_report_em` 的「应收账款」两年对比。

### P2（杜邦 / 分红 / 重述）

7. **`net_margin` / `asset_turnover` / `equity_multiplier` / `roic`**：`stock_financial_analysis_indicator` 相应字段 + 计算。
8. **`dividend_yield` / `payout_ratio`**：`stock_a_indicator_lg` 的 `dv_ratio` + 每股股利/每股收益。
9. **`restatement_flag`**：公告检索 `stock_zh_a_disclosure_report_cninfo` 匹配「前期会计差错更正 / 更正公告」关键词。

- **建议新增测试**（数据层补完后）：
